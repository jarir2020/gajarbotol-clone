# GajarBotol Clone - Free Online Tools

A collection of free online tools built with Node.js/Express backend and vanilla JavaScript frontend.

## Features

- **QR Code Generator** - Generate QR codes for URLs, text, and more
- **Password Generator** - Create strong, secure passwords
- **URL Shortener** - Shorten long URLs (simulated)
- **Text Converter** - Convert text case, reverse, count words/characters
- **Base64 Encoder/Decoder** - Encode and decode Base64
- **Color Converter** - Convert between HEX, RGB, and HSL
- **Word Counter** - Count words, characters, sentences, paragraphs
- **Lorem Ipsum Generator** - Generate placeholder text
- **Case Converter** - Quick text case conversion
- **Random Number Generator** - Generate random numbers
- **Online Stopwatch** - Precision stopwatch with lap functionality
- **Unit Converter** - Convert length, weight, temperature units

## Installation

```bash
npm install
```

## Usage

```bash
npm start
```

Then open http://localhost:3000 in your browser.

## Development

```bash
npm run dev
```

## Tech Stack

- **Backend**: Node.js, Express
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Dependencies**: qrcode, crypto-js, axios
